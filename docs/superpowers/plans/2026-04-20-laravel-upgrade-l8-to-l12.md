# Laravel 8 → 12 Upgrade Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade the clinic-ms app from Laravel 8 (PHP 7.4) to Laravel 12 (PHP 8.2+), making it compatible with PHP 8.3 on the server and PHP 8.5 locally.

**Architecture:** Two sequential phases with a verified checkpoint between them. Phase 1 (Tasks 1–7) upgrades to Laravel 10, which keeps the L8 application skeleton and runs on PHP 8.1–8.3. Phase 2 (Tasks 8–12) upgrades to Laravel 12, which restructures the application skeleton to the L11/L12 "slim" format and runs on PHP 8.2–8.5.

**Tech Stack:** Laravel 12, PHP 8.2, Blade, MySQL, yajra/laravel-datatables ^11, laravelcollective/html ^6.4, PHPUnit 11, SQLite (tests)

## Task 5: Fix `RouteServiceProvider` and move diagnosis API routes to web

**Files:**
- Modify: `app/Providers/RouteServiceProvider.php`
- Modify: `routes/api.php`
- Modify: `routes/web.php`

Two changes combined here:
1. `RouteServiceProvider` currently concatenates `null . "\\API"` because `$namespace` is commented out — fix this.
2. The two diagnosis routes use `auth` (session guard) but live in `api.php` which has no session middleware. Move them to `routes/web.php` so session auth works correctly (also resolves the security review finding).

- [ ] **Step 1: Update `RouteServiceProvider.php`**

  Replace the entire file:

  ```php
  <?php

  namespace App\Providers;

  use Illuminate\Cache\RateLimiting\Limit;
  use Illuminate\Foundation\Support\Providers\RouteServiceProvider as ServiceProvider;
  use Illuminate\Http\Request;
  use Illuminate\Support\Facades\RateLimiter;
  use Illuminate\Support\Facades\Route;

  class RouteServiceProvider extends ServiceProvider
  {
      public const HOME = '/home';

      public function boot(): void
      {
          $this->configureRateLimiting();

          $this->routes(function () {
              Route::prefix('api')
                  ->middleware('api')
                  ->group(base_path('routes/api.php'));

              Route::middleware('web')
                  ->group(base_path('routes/web.php'));
          });
      }

      protected function configureRateLimiting(): void
      {
          RateLimiter::for('api', function (Request $request) {
              return Limit::perMinute(60)->by($request->user()?->id ?: $request->ip());
          });
      }
  }
  ```

- [ ] **Step 2: Remove the diagnosis routes from `routes/api.php`**

  In `routes/api.php`, delete the `Route::middleware('auth')->group(...)` block. The file should end as:

  ```php
  <?php

  use Illuminate\Http\Request;
  use Illuminate\Support\Facades\Route;

  Route::middleware('auth:api')->get('/user', function (Request $request) {
      return $request->user();
  });
  ```

- [ ] **Step 3: Add diagnosis routes to `routes/web.php`**

  Open `routes/web.php` and append at the end (inside the existing `Auth::routes()` context, after the authenticated routes group):

  ```php
  // Diagnosis autocomplete routes — session-authenticated AJAX endpoints
  Route::middleware('auth')->group(function () {
      Route::get('/api/visits/diagnosis', [App\Http\Controllers\API\VisitAPIController::class, 'getDistinctDiagnosis'])->name('visits.diagnosis');
      Route::get('/api/visit/diagnosis/{id}', [App\Http\Controllers\API\VisitAPIController::class, 'getDiagnosisByVisitId'])->name('visit.diagnosis.by.id');
  });
  ```

  > The `/api/` prefix is kept in the URL so the existing AJAX calls in the Blade views (`url: '/api/visits/diagnosis'`) continue to work without any JavaScript changes.

- [ ] **Step 1: Conversion reference table**

  | Form helper | Plain HTML equivalent |
  |---|---|
  | `{!! Form::open(['route' => 'x']) !!}` | `<form method="POST" action="{{ route('x') }}">@csrf` |
  | `{!! Form::open(['route' => ['x', $id]]) !!}` | `<form method="POST" action="{{ route('x', $id) }}">@csrf` |
  | `{!! Form::model($m, ['route' => ['x', $m->id], 'method' => 'patch']) !!}` | `<form method="POST" action="{{ route('x', $m->id) }}">@csrf @method('PATCH')` |
  | `{!! Form::close() !!}` | `</form>` |
  | `{!! Form::label('field', 'Label:', ['class' => 'x']) !!}` | `<label for="field" class="x">Label:</label>` |
  | `{!! Form::text('field', null, ['class' => 'x']) !!}` | `<input type="text" id="field" name="field" value="{{ old('field') }}" class="x">` |
  | `{!! Form::text('field', $val, ['class' => 'x']) !!}` | `<input type="text" id="field" name="field" value="{{ old('field', $val) }}" class="x">` |
  | `{!! Form::textarea('field', null, ['class' => 'x', 'rows' => '5']) !!}` | `<textarea id="field" name="field" class="x" rows="5">{{ old('field') }}</textarea>` |
  | `{!! Form::textarea('field', $val, ['class' => 'x', 'rows' => '5']) !!}` | `<textarea id="field" name="field" class="x" rows="5">{{ old('field', $val) }}</textarea>` |
  | `{!! Form::hidden('field', $val) !!}` | `<input type="hidden" name="field" value="{{ $val }}">` |
  | `{!! Form::submit('Save', ['class' => 'x']) !!}` | `<button type="submit" class="x">Save</button>` |
  | `{!! Form::password('field', ['class' => 'x']) !!}` | `<input type="password" id="field" name="field" class="x">` |
  | `{!! Form::email('field', null, ['class' => 'x']) !!}` | `<input type="email" id="field" name="field" value="{{ old('field') }}" class="x">` |
